# 01 — El editor abre con un proyecto vacío

**What to build:** La persona abre el editor y encuentra un proyecto sin escenas, con la biblioteca vacía. La barra muestra el nombre del proyecto y una duración del short de cero. Puede pasar entre Biblioteca, Escenas, Escena y Apariencia, y en la pantalla hay un solo modo además de la barra. Cada modo vacío se entiende: no hay medios, no hay escenas, no hay una escena que editar. El feeling inicial ya se ve en la aplicación.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] La barra muestra ese nombre y una duración del short de cero
- [ ] La barra sigue visible en los cuatro modos
- [ ] En la pantalla hay un solo modo a la vez
- [ ] La persona puede llegar a Biblioteca, Escenas, Escena y Apariencia
- [ ] Biblioteca muestra una lista vacía
- [ ] Escenas muestra una lista vacía

- [ ] El feeling inicial está aplicado: tipografía de 16 px, color del texto `#1a1a1a`, color de fondo `#f7f7f5`
